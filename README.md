# Lanternwake Windows releases

This repository is reserved for official Windows distribution binaries and public release notes for Lanternwake.

**Release preparation is in progress. No Windows download or automatic-update release is available here yet.**

Play the current web game at https://solacekingdom.pages.dev/play/solace/ .

Private development history, player saves, account data, and private signing keys do not belong in this repository. A public repository permits viewing and downloading; it does not give visitors permission to modify the official releases.

Windows update content must pass the launcher's pinned-signature and file-integrity checks. Content signing is separate from Windows publisher signing, and does not imply that Windows SmartScreen warnings are eliminated.
